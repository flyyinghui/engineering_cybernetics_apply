# 理论对齐的第一性原理补丁模式

**日期**: 2026-05-18  
**案例**: SPSGAN 12-D 四大推测性跳跃修复

## 模式定义

当代码中存在"推测性跳跃"（数学上有吸引力但缺乏物理推导的手动约束）时，按以下模式进行第一性原理替换：

## 四步替换法

### Step 1: 识别跳跃的本质

| 跳跃类型 | 判断信号 | 例子 |
|----------|---------|------|
| 数学恒等式误用 | 数论恒等式被用作物理约束（对不满足前提条件的对象） | Σk³=(Σk)² 用于矩阵特征值 |
| 手动阈值 | 魔法数字出现在物理判断中，无推导来源 | Θ_BH_Collapse=50.0 |
| 隐式假设 | 物理过程被简化为计数/阈值，缺少显式建模 | 结晶=连续5步方差<threshold |
| 残缺对偶 | 双边理论只实现了一侧 | 有体引力无边界CFT |

### Step 2: 映射到第一性原理

| 跳跃 | 第一性原理 | 物理文献 |
|------|----------|---------|
| 数论对偶 | 规范群的相签名守恒 | SL(6,C)分解为(S,T)子空间 |
| 手动BH阈值 | Hawking辐射+Page曲线 | Hawking 1974, Page 1993 |
| 隐式结晶 | Caldeira-Leggett开放量子系统 | CL 1983, Physica A 121 |
| 残缺对偶 | WZW边界CFT | Witten 1984, CMP 92 |

### Step 3: 对齐理论参考文档

在实施前，必须：
1. 读取项目的理论参考文档
2. 提取临界参数（θ_stable, θ_crit, CDM比例等）
3. 确保新约束与文档描述一致
4. 引用文档具体行号

**失败模式**: 用户说"修改后的...与参考MD保持一致" → 没有先读文档就开始改 → 方向性错误

### Step 4: 保留向后兼容

| 做法 | 原因 |
|------|------|
| 旧函数名在注释中保留 | 便于代码考古 |
| 新增 Config 参数控制新行为 | 可切换新旧模式 |
| 旧 global 变量改为新名 | 保持接口一致 |
| try/except 包裹新逻辑 | 降级不崩溃 |

## 五类可替换的推测性约束

### 1. 数学恒等式 → 群论守恒律
```
旧: Σk³=(Σk)² (数论)
新: ΣS=6, ΣT=6 (SL(6,C)相签名)
```

### 2. 手动阈值 → 物理速率方程
```
旧: if chi_norm > 50.0: trigger_collapse()
新: T_H = 1/M_eff; rad_power = 1/M_eff²; if rad_power > threshold: trigger()
```

### 3. 计数判断 → 开放系统退相干
```
旧: if stable_count >= 5: crystallized = True
新: T_env = std(λ); γ = η·T_env; window_eff = base/(1+γ); tol_eff = tol₀·(1+T_env/T_crit)
```

### 4. 残缺对偶 → 补充边界理论
```
旧: 仅有体RYM流
新: 新增 WZW 边界CFT + GKPW配分函数约束
```

### 5. 固定权重 → 动态偏差耦合
```
旧: M_geo_penalty = 100.0
新: M_geo_dynamic = 1.0 + α · phase_imbalance
```
